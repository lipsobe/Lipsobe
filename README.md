## TramitAI — What I've worked on

AI-powered legal tool for electoral lawyers in Mexico. Real client, real production, used daily. I built on top of the project's existing architecture — owning specific modules end to end over 6 months.

| 25k docs indexed | 30 → 80% utility rating | 103 ground-truth docs curated |
|:---:|:---:|:---:|

- **AI prompts** — designed and iterated the summarizer and classifier prompts, including the legal argumentation logic (agravios)
- **Search backend** — defined the BM25 reranking logic and tuned search parameters based on real lawyer feedback
- **Document exporter** — built the Word document generator following the real electoral law brief structure

- **AWS deployments** — managed Lambda, CDK, and CloudFront deploys across staging and production environments
